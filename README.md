# Static Room

Protótipo inicial da loja Static Room: uma experiência visual deliberadamente irregular, construída como pôster vivo, arquivo e loja ao mesmo tempo.

## Abrir localmente

Abra `index.html` diretamente no navegador ou sirva a pasta com qualquer servidor estático.

## Estrutura

- `index.html` — conteúdo e estrutura
- `styles.css` — direção visual, animações e responsividade
- `script.js` — entrada, elementos arrastáveis, carrinho e interações
- `assets/` — identidade visual da Static Room
